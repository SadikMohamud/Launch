# Sources and Material

## Material Read
- Design system: Computed tokens (canvas-50, ink-900, border-200, accent-terra) extracted via MiMic token engine.
- Motion curves: Cubic-bezier easing parameters from layout and animation styles.
- Typography: Playfair Display (editorial serif) and Plus Jakarta Sans (body UI).

## Captured Assets Used
- Hero kinetic motion recording: Awwwards Pack +26 Hero Animations (hero-1.mp4).
- Generative noise background: Awwwards Pack +10 Background Animations (bg-1.mp4).
- Production video render: Deterministic 60fps Hyperframes render with baked frame 0 poster.
